# 📊 CodeAlpha Data Analytics Internship

This repository contains my projects completed as part of the **CodeAlpha Data Analytics Internship**.

The internship provided practical experience in **data analysis, exploratory data analysis, data visualization, and Natural Language Processing (NLP)** using Python and related data analytics tools.

---

## 🚀 Projects

### 📌 Task 1 — Exploratory Data Analysis (EDA)

An exploratory data analysis project focused on understanding and analyzing a dataset using Python.

**Key areas covered:**
- Data loading and inspection
- Data cleaning
- Missing-value analysis
- Duplicate-value detection
- Descriptive statistics
- Numerical and categorical analysis
- Correlation analysis
- Outlier identification
- Exploratory visualizations

**Technologies:**
`Python` `Pandas` `NumPy` `Matplotlib` `Seaborn`

📂 **Project:** [Task-1-EDA](./Task-1-EDA)

---

### 📌 Task 2 — Data Visualization

A data visualization project focused on transforming data into meaningful charts and visual insights.

**Key areas covered:**
- Data preprocessing
- Distribution analysis
- Category comparison
- Trend analysis
- Relationship analysis
- Correlation visualization
- Statistical visualization

**Visualizations include:**
- Bar Charts
- Line Charts
- Histograms
- Scatter Plots
- Box Plots
- Heatmaps

**Technologies:**
`Python` `Pandas` `NumPy` `Matplotlib` `Seaborn`

📂 **Project:** [Task-2-Data-Visualization](./Task-2-Data-Visualization)

### 📌 Task 3 — Sentiment Analysis

A Natural Language Processing project that analyzes textual data to identify sentiment, emotions, trends, and frequently occurring negative keywords.

**Key features:**
- Positive / Negative / Neutral sentiment classification
- VADER sentiment analysis
- TextBlob sentiment analysis
- Emotion detection
- Sentiment analysis by source
- Sentiment trend analysis
- Negative keyword analysis
- Automated report generation
- Data visualization

**Technologies:**
`Python` `Pandas` `NLTK` `VADER` `TextBlob` `Matplotlib` `Seaborn`

📂 **Project:** [Task-3-Sentiment-Analysis](./Task-3-Sentiment-Analysis)
